# Octane Lending

> Octane (Octane Lending, Inc.) is a New York City fintech founded in 2014 that makes powersports,
> outdoor power equipment and recreational-vehicle financing as simple as paying cash. It runs an
> end-to-end digital lending platform — soft-pull prequalification, real-time credit decisioning and
> eContracting through its in-house lender Roadrunner Financial, Inc., and loan servicing — for more
> than 4,000 dealer partners and 30-plus OEMs.

Generated by API Evangelist from the public Octane surface on 2026-08-04. Octane does not publish an
llms.txt of its own (https://octane.co/llms.txt returns 404).

## API status

- Octane publishes **no public developer portal, API reference, or machine-readable specification**.
- A partner API does exist: dealer-management-system vendors (AppOne, Ekho and similar) submit
  credit applications and receive real-time decisions through it, but credentials are coordinated
  privately by an Octane account manager — there is no self-service signup and no public docs.
- The Dealer Portal 2.0 single-page app at https://dealer.octane.co calls
  https://los.octane.co (its `API_BASE_URL`), which is authenticated and undocumented. No
  OpenAPI/Swagger/GraphQL/MCP surface was reachable there anonymously.
